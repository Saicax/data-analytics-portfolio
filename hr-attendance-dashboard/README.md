# HR Attendance Dashboard

An Excel dashboard tracking employee attendance by department.

## What it shows

- **Absence rate by department** — which teams have the highest absence, at a glance
- **Monthly trend** — how absence moves over time
- All views are **aggregated by department** (no individual employee names), the way a real HR report should be

## Sheets

| Sheet | Contents |
|---|---|
| `DASHBOARD` | The visual dashboard: absence-rate chart by department + monthly trend |
| `Data` | Attendance records (department, date, present/absent, reason) |
| `Absence Breakdown by Dept` | Summary calculations behind the charts |

## Techniques

`COUNTIFS` summaries · bar/line charts · color scaling · month-by-department matrix
