# Inventory Management System

An Excel-based inventory system: products, transactions, stock levels, and reporting in one workbook.

## What it does

- **Products** — product catalog with details
- **Transactions** — stock in/out log
- **Inventory** — live stock levels and inventory value
- **Report** — summary reporting

## Sheets

| Sheet | Contents |
|---|---|
| `DASHBOARD` | Navigation hub + key inventory metrics |
| `Products` | Product master list |
| `Transaction` | Stock movement log |
| `Inventory` | Current stock levels and inventory value |
| `Report` | Summary reports |

## Techniques

Multi-sheet workbook design · lookup formulas · dashboard navigation · inventory valuation
