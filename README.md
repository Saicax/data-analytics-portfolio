# Sameer — Data Analytics Portfolio

Projects built with SQL (MySQL) and Excel — each one answers a real business question, not just a tutorial exercise.

## Projects

| Project | Question it answers | Tools |
|---|---|---|
| [E-commerce Sales Analysis](ecommerce-sales-analysis/) | What are our top products, slowest month, and do repeat customers spend more? | MySQL, Excel |
| [Movie/Streaming Analysis](movie-streaming-analysis/) | Do higher budgets buy better ratings, and which genre gives the best rating per dollar? | MySQL, Excel |
| [HR Employee Attrition](hr-attrition-analysis/) | Which factors — department, overtime, salary band, tenure — are most linked to employees quitting? | MySQL, Excel |
| [Data Cleaning Project](data-cleaning-project/) | Turn a badly merged layoffs export into one clean table you can actually trust | MySQL |
| [HR Attendance Dashboard](hr-attendance-dashboard/) | Which departments have the highest absence rates, and how do they trend? | Excel |
| [Inventory Management](inventory-management/) | Track products, transactions, and inventory value in one system | Excel |
| [Personal Budget Tracker](personal-budget-tracker/) | Where does my money go each month? | Excel |
| [Sales Dashboard](sales-dashboard/) | Bike buyer trends and sales performance at a glance | Excel |

## Skills

- **SQL:** querying, joins, CTEs, window functions, data cleaning, `LOAD DATA INFILE`, JSON parsing
- **Excel:** dashboards, pivot tables, charts, conditional formatting
- **Data storytelling:** turning query results into plain-English findings

*More projects are added as they're completed — this portfolio is a work in progress, like any good analyst's.*
