# Sales Dashboard
![Dashboard](sales_dashboard)
An Excel sales dashboard built on bike-buyer data, with pivot tables driving the visuals.

## What it shows

- **Dashboard** — KPI overview and charts
- **Pivot Table** — the analysis engine behind the dashboard
- **Bike Buyers** — the underlying customer/purchase data
- **Working Sheet** — data prep and calculations

## Sheets

| Sheet | Contents |
|---|---|
| `Dashboard` | Visual summary: KPIs and charts |
| `bike_buyers` | Raw buyer data |
| `Pivot Table` | Pivot-driven aggregations |
| `Working Sheet` | Data preparation and helper calculations |

## Techniques

Pivot tables · dashboard design · KPI cards · data preparation
